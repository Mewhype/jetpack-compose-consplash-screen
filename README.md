#  Jetpack Compose Splash Screen

Una experiencia de onboarding moderna desarrollada con Kotlin y Jetpack Compose, enfocada en una aplicación de calzado con múltiples pantallas splash, navegación personalizada y una interfaz visual atractiva orientada a la experiencia de usuario.

Este proyecto fue construido como parte de mi proceso de aprendizaje y crecimiento en desarrollo Android, aplicando principios de diseño UI moderno, organización de código y navegación entre pantallas.

##  Características

* Splash principal automático con logo
* Secuencia onboarding con múltiples pantallas
* Botón personalizado para navegación
* Diseño moderno enfocado en experiencia visual
* Estructura organizada por módulos
* Interfaz desarrollada completamente con Jetpack Compose
* Navegación limpia y reutilizable
